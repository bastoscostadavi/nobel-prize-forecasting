# Codex independent 2026 Peace Prize draft

Prepared 3 October 2026 for a later user-led merge with Claude. This directory preserves the independent input and does not designate a consolidated simulation list.

- `candidates.md`: readable list of 108 candidates, grouped by theme, with sources and reservations; also includes eight repeat-award possibilities.
- `candidates.json`: complete structured data, aliases, evidence labels, overlap links, ten possible joint configurations, source registry and limitations.
- `candidates.csv`: flat main pool with direct source URLs for merging. The repeat-award supplement is in JSON and Markdown only.

Main pool: 53 individuals, 49 organizations, 4 networks, 2 partnerships. IDs are alphabetical, not ranks. Candidate keys are stable merge identifiers; numeric IDs may change after merging.

Sources establish activities, awards or public claims. They do not establish inclusion among the secret official nominees. The ordinary nomination deadline was 31 January 2026; the first committee meeting was 26 February. Some public nomination announcements were later, and their submission dates remain unresolved.

Related person/organization entries describe alternative recipients of overlapping work. Avoid giving the same case extra weight merely because several recipient configurations are listed. Broad author additions and public speculation should not be treated as equally evidenced candidacies. No probabilities are assigned.
