# 2026 Chemistry candidate list — independent Codex draft

Prepared **3 October 2026** (America/Chicago). **72 discovery-centered entries and 179 distinct names** in provisional recipient pools. This is a broad input for merging with Claude's independently prepared list, not a ranked shortlist or a set of actual nominations.

The format follows the Medicine list. A name pool can exceed three; a final award must select at most three people in total. Known deceased contributors are recorded separately. 7 entries are explicitly retained for substantial boundary or overlap review, rather than silently excluded. All entries have reservations; inclusion does not imply equal plausibility.

- `candidates.json`: full scientific basis, rationale, reservations, attribution, historical contributors, prior-award flags, related keys and source registry.
- `candidates.csv`: the same four-column interface as Medicine (`candidate_id, discovery, subfield, credited_names`).
- `research_notes.md`: readable dossiers with linked sources for every entry.
- `attribution_review.md`: merge guidance, priority concerns, eligibility limits and exclusions.

The existing Claude Chemistry files were not read. This directory is a separate draft; it does not replace the eventual merged Chemistry candidate list.
